# Cross-validation results

Outputs of `notebook/ser_fer_fusion_ravdess_cv.ipynb` (code in `cv/`).

- `folds.json` is the fold assignment (generated by `cv.folds.make_folds(6, seed=42)`). The notebook
  checks that it regenerates exactly this assignment.
- `RESULTS_CV.md` (all tables), the CSV/JSON tables and the PNG figures are written by the
  analysis, which reads only the saved run outputs (no retraining):
  `python -m cv.analysis --results "<RESULTS_DIR>" --out results_cv`.

## Folds

Six folds of four test actors, each 2 male (odd ids) + 2 female (even ids). Fold *k* validates on
the test actors of fold *k+1* and trains on the remaining 16, so every actor is tested once and
used for validation once.

| Fold | Test actors | Validation actors |
|---|---|---|
| fold0 | 1, 12, 15, 24 | 6, 10, 13, 19 |
| fold1 | 6, 10, 13, 19 | 7, 16, 20, 23 |
| fold2 | 7, 16, 20, 23 | 4, 5, 11, 18 |
| fold3 | 4, 5, 11, 18 | 9, 14, 21, 22 |
| fold4 | 9, 14, 21, 22 | 2, 3, 8, 17 |
| fold5 | 2, 3, 8, 17 | 1, 12, 15, 24 |

## What is run and reported

- **Speech systems:** matched frozen probes for wav2vec 2.0 and emotion2vec (RQ2), the
  weighted-layer probe (W2V2-WLP) and LoRA (W2V2-LoRA) pipelines on wav2vec 2.0 (RQ3), and the
  final-layer probe on emotion2vec (E2V-LP); each is also fused with FER (RQ1).
- **Seeds:** systems trained on cached frozen features (both matched probes, E2V-LP), the FER
  model and their fusions run seeds 42, 43 and 44. The backbone-in-the-loop systems (W2V2-WLP,
  W2V2-LoRA) run seed 42 only; their fusions use the seed-42 FER model. Seed 42 runs for every
  system first. Set in the notebook config (`SYSTEM_SEEDS`, `FER_SEEDS`).
- **LoRA is not evaluated under the matched protocol.** Matching it would remove SpecAugment,
  which the LoRA recipe relies on.

## Tests

`python -m pytest tests -q` checks that the emotion2vec_base layout exposes 13 hidden states, that
both hidden-state modules of the matched protocol stay in eval mode and are deterministic, and
that the fusion temperatures are always positive and at the validation cross-entropy optimum.

## Run outputs (in `RESULTS_DIR` on Drive)

```
folds.json  clips.csv  label_space.json  alignment.json  params.json  config_<time>.json
runs/<system>/<fold>/seed<seed>/<cfg>.npz|.json   one training run: val/test logits, labels, HF row
                                                  indices, test predictions; best val loss, epochs,
                                                  trainable parameters, wall time, recipe
runs/<system>/<fold>/seed<seed>/selected.json     validation-selected config of the grid
runs/fer/<fold>/seed<seed>/xgbrf.npz|.json        FER margins (val/test)
fusion/<system>+fer/<fold>/seed<seed>.npz|.json   fused test probabilities and the two temperatures
```

`clips.csv` maps each HF row index to the RAVDESS file id, actor, gender, emotion and intensity.

## FER only, 8 classes (`fer8/`)

`python -m cv.fer8 --blendshapes "<blendshape CSV dir>" --out results_cv/fer8` (blendshapes: [Google Drive](https://drive.google.com/drive/folders/1omlBivvIL68xhqAdRY5lSjJNIO8DaIN7)) (or
`notebook/fer8_eval.ipynb` on Colab, CPU only) evaluates the face model alone with 8 classes (calm
kept apart from neutral) and with 7 classes, on the 6 CV folds and on the 5 actor folds of
Luna-Jiménez et al. (2022), training on every actor that is not held out (no validation actors:
XGBRF has fixed hyperparameters and no early stopping). Same features, XGBRF settings and
audio-face pairing as the main study; seeds 42, 43, 44. `fer8/RESULTS_FER8.md` has the tables,
the calm/neutral confusion and the comparison with the published face-only results; it is the
full rendered output of the Colab run (its CSV outputs and figure stayed on Drive). The script
reads `clips.csv` (the clip table of the main run) and `folds.json` from this folder.
